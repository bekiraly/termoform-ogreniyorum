# Termoform Öğreniyorum

Servo termoform makinesinin çevrim ayarlarını oynayarak öğreten ücretsiz, reklamsız eğitim uygulaması.

- Web sayfası: `docs/index.html` (GitHub Pages ile yayınlanır)
- Android uygulaması: `android/` — sayfayı internetten açar, internet yoksa APK içindeki kopyayı açar.
- Her `main` güncellemesinde GitHub Actions yeni APK derler ve **Releases** bölümüne koyar.

Son APK: `https://github.com/bekiraly/termoform-ogreniyorum/releases/latest/download/termoform-ogreniyorum.apk`
